Character Preset Manager (CET) 3.1.4

Install the complete package in your main Cyberpunk 2077 folder. You need
RED4ext, redscript and Codeware. CET is optional for technical tools, and CDPR's
REDmod DLC is not required. Close and restart the game after updating.

Open a supported appearance editor and select a preset row. Choose Load to
apply it, or enter a name and choose Save Preset to save your current look.
Manage Presets opens folders, notes, tags, sharing, backups, Trash, recovery,
settings and Help inside the editor. Hide Presets clears the panel so you can
reach the game's controls.

Presets and Data now go under red4ext/plugins/CharacterPresetManager. Back up
the complete old Character Presets and Data folders before updating. Leave
those folders in the old CET mod folder for the first start. The native plugin checks each copy and keeps your original files.

If old files differ from those at the new location, copies are kept under
Data/Migration/Conflicts. The tools stop so you can review them. Once copying
finishes, use the native library as your active copy.

New presets use readable format 8. Older compatible CPM and ACU files update
only when you overwrite them or save their notes or tags. Loading keeps an
existing character's gender and body type. Missing appearance mods can prevent
a full load, so use Check Compatibility and review your appearance.

Cancel Load stops further changes. Choices already applied stay visible; use
Recovery to restore an earlier appearance. Empty Trash, Clear History and
Delete Backup permanently delete saved files and ask for confirmation.

Assign native keys inside Manage Presets. Existing CET key assignments can
still trigger the same actions, but close CET before using them.

I have not tested this build inside the game. Read the project README and
validation report for the checks I have completed and those still needed.
