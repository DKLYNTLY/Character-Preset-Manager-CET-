Character Preset Manager (CET) 3.1.4

Install the complete package into the main Cyberpunk 2077 folder. RED4ext,
redscript and Codeware are required. CET is optional for technical tools.
CDPR's REDmod DLC is not required. Fully restart after updating.

Open a supported appearance editor. Select a preset row, then Load. Enter a
name and choose Save Preset to save. Manage Presets opens folders, notes, tags,
sharing, backups, Trash, recovery, settings and Help inside the editor.
Hide Presets clears the panel so you can reach the game's controls.

Presets and Data now belong under red4ext/plugins/CharacterPresetManager.
Back up the old Character Presets and Data folders before updating. Keep them
in the old CET mod folder for the first start. The native plugin copies and
verifies them, preserving originals. Conflicts are kept separately under
Data/Migration/Conflicts. Tools stop until conflicting copies are reviewed.
After completed migration, use the native library as the active copy.

New presets use readable format 8. Older compatible CPM and ACU files are
rewritten only when overwritten or when their notes or tags are saved. Loading
does not change an existing character's gender or body type. Missing appearance
mods can prevent a complete load. Check Compatibility and review the appearance.

Cancel Load stops further changes; applied choices remain visible. Recovery
can restore an earlier appearance. Empty Trash, Clear History and Delete Backup
permanently remove saved files and require confirmation. Assign native keys
inside Manage Presets. CET assignments remain optional aliases; close CET before
using keys.

I have not checked this build inside the game. See the project README and
validation report for completed checks and outstanding work.
